| T-02-02-03 | Spoofing (tabnabbing) | External paper links | mitigate | No `target="_blank"` anywhere → no tabnabbing surface (Phase 1 mitigation T-01-03-05 preserved). Acceptable UX cost: external papers open in the same tab; user uses back button to return. |
| T-02-02-04 | Information Disclosure | TLDR text | accept | Owner-published abstracts only; nothing private. |
| T-02-02-05 | Repudiation / Integrity | Verbatim content claim | mitigate | CONT-09 invariant: no fabricated entries; missing data is flagged in SUMMARY rather than invented. Manual cross-check during extraction. |
| T-02-02-06 | Denial of Service | Page weight | accept | ~90-line static HTML with no images; first-paint cost is trivial. |
