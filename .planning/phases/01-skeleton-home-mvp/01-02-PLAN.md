<interfaces>
Plan 03 (`index.html`) will use the following CSS selectors/classes/elements. They must be present and styled in `style.css`:

Site shell selectors:
- `:root` (CSS custom properties block — see UI-SPEC §Color CSS variables, §Spacing Scale)
- `body`, `main`, `header`, `section`, `nav` (semantic-element baseline styling)
- `.skip-link` (visually hidden, focus-visible)
- `nav[aria-label="Site"]` (top nav container)
- `nav a` and `nav [aria-current="page"]` (active state in `--accent`, no underline)

Home page specific selectors:
- `header .headshot` (or `.headshot`) — circular profile photo, 120×120 desktop, 96×96 mobile, `border-radius: 50%`, `object-fit: cover`, `object-position: center 25%`
- `header h1` — name, 32px desktop / 26px mobile, weight 700, `letter-spacing: -0.01em`
- `header .role` — small muted role line, 14px, `--text-muted`
- `header .contact-strip` (or `nav.contact` — either name; pick `.contact-strip` for clarity) — inline links separated by middot
- `section#about p` — bio body, 17px desktop / 16px mobile, line-height 1.6
- `section#news h2` and `#news-heading` — "What's New?" heading, 22px weight 700
- `.news-list` — the scrollable container (max-height 380px desktop / 320px mobile, overflow-y auto, border, radius, custom scrollbar)
- `.news-list:focus` — focus ring on container using `--accent` 2px outline + 2px offset
- `.news-entry` — each entry paragraph, with `.news-date` (muted small) and `.news-body` spans

Link styling (global):
- `a` default — `color: var(--accent)`, `text-decoration: underline`, `text-decoration-thickness: 1px`, `text-underline-offset: 3px`
- `a:hover` — `text-decoration-thickness: 2px`
- `a:visited` — same color as default (no purple shift)
- `a:focus` (or `:focus-visible`) — 2px outline `var(--accent)` with 2px offset

Breakpoints (CSS-only, no JS):
- Mobile: `@media (max-width: 639px)` — body 16px, page padding 24px, headshot 96×96, news max-h 320px, H1 26px
- Tablet+ (default, no media query needed): body 17px, page padding 32px, headshot 120×120, news max-h 380px, H1 32px
- Desktop (`@media (min-width: 1024px)`): page padding 40px. Otherwise identical to tablet.

Reduced motion:
- `@media (prefers-reduced-motion: reduce)` — remove any transitions (currently a no-op since Phase 1 has no animations beyond `text-decoration-thickness` change on hover, which UI-SPEC explicitly permits).

These selectors form the contract between Plan 02 and Plan 03. Plan 03 will hard-code class names against this list; do not rename them.
</interfaces>

    5. `/* Skip link */` — `.skip-link` visually hidden by default (`position: absolute; left: -9999px;` or the canonical `clip-path` pattern); on `:focus` reposition to top-left visible with `--accent` background.
    6. `/* Site nav */` — `nav[aria-label="Site"]` styles: inline horizontal layout (a list `ul` with `display: flex; gap: var(--space-2); list-style: none; padding: 0; margin: 0 0 var(--space-8) 0;`), or use direct `<a>` children separated by the middot rendered via `::after` on each link except the last — UI-SPEC §Top navigation specifies middot `·` flanked by space as separator. Inactive links: `color: var(--text-strong); text-decoration: none; underline on :hover only`. `[aria-current="page"]` (or `<span>` rendered as active): `color: var(--accent); text-decoration: none;`. Pick whichever middot rendering technique (CSS `::after` content vs inline text in HTML) feels cleanest — but pick one and use it consistently. RECOMMENDED: use inline text middots in HTML (Plan 03) so the CSS stays simpler; declare that decision in the SUMMARY.

    Apply all values verbatim from UI-SPEC. Do NOT invent new tokens, do not collapse the spacing scale, do not change any hex value.
